## ❻ FAQ

### What data can you get from the Ahrefs Scraper?

The Ahrefs Scraper can extract a wide range of SEO data from Ahrefs, including Domain Rating (DR), URL Rating (UR), Ahrefs Rank, organic traffic estimates, top pages, keyword rankings, SERP features, backlinks including backlink profiles, broken links, competitor analysis, and top website rankings.

### Is Bulk URL processing supported?
